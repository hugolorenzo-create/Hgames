1️⃣ Información General

Nombre del proyecto: HGAMES
Tipo de plataforma: Web pública de juegos online
Propietario / Administrador: Hugo Lorenzo
Acceso: Público y gratuito para jugadores

HGAMES.IO será una plataforma web donde los usuarios podrán jugar juegos directamente desde el navegador, sin necesidad de descargas externas obligatorias. El sitio incluirá tanto juegos oficiales (con permiso o licencia adecuada) como juegos Indie desarrollados por el administrador.

2️⃣ Objetivo del Proyecto

El objetivo principal de HGAMES es:

Crear una plataforma de juegos accesible desde cualquier navegador.

Permitir que solo el administrador pueda subir y gestionar juegos.

Ofrecer juegos Indie propios.

Construir una marca sólida dentro del sector de juegos web.

En el futuro, generar ingresos mediante monetización.

3️⃣ Modelo de Funcionamiento
🔹 Acceso Público

Cualquier persona podrá:

Entrar a la web.

Navegar por categorías.

Jugar directamente desde el navegador.

Acceder gratuitamente al contenido disponible.

🔹 Control Administrativo

Solo el administrador podrá:

Subir nuevos juegos.

Modificar el diseño.

Eliminar contenido.

Gestionar actualizaciones.

La plataforma puede alojarse gratuitamente utilizando:

GitHub

GitHub Pages

Esto permite que la web sea pública mientras solo el propietario tenga acceso para editarla.
